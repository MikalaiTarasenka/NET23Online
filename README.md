# FaunaWorld — Информационная система «Мир животных»

Веб-приложение для управления зоопарками, видами и семействами животных с системой бронирования билетов, комментариями и push-уведомлениями в реальном времени.

## Возможности

### Пользователи
* **Регистрация и вход** — авторизация в системе.
* **Галерея** — просмотр случайных животных через внешнее API.
* **Поиск** — фильтрация видов по названию, семейству или месту обитания.
* **Факты** — чтение и добавление интересных фактов о животных.
* **Зоопарки** — просмотр списка объектов с пагинацией.
* **Билеты** — бронирование с автоматической генерацией QR-кода.
* **Комментарии** — отправка отзывов к зоопаркам через AJAX.
* **Уведомления** — получение push-сообщений через SignalR.
* **Профиль** — управление личными данными (имя, телефон, язык).

### Администрация и модераторы
* **Контент** — создание, редактирование и удаление семейств, видов животных и зоопарков.
* **Связи** — привязка видов животных к конкретным зоопаркам.
* **Маркетинг** — управление акциями в зоопарках.
* **Контроль** — доступ к панели управления (Moderating).

## Архитектура

Проект построен по принципу классической многоуровневой архитектуры (Layered / N-tier Architecture) и разделён на следующие логические слои:

* **Presentation (AnimalWorld.Web, AnimalWorld.Api)** — MVC-контроллеры, Razor-представления, Minimal API, SignalR-хабы, планировщик Quartz.
* **Business Logic (AnimalWorld.Core)** — бизнес-правила, сервисы, DTO, вспомогательные классы.
* **Data Access (AnimalWorld.Data)** — модели данных (EF Core), репозитории, конфигурация контекста БД, миграции.

*Примечание: Проект `AnimalWorld.Core` имеет прямую ссылку на `AnimalWorld.Data`, что характерно для классического многоуровневого подхода, где бизнес-логика напрямую взаимодействует со слоем доступа к данным.*

## База данных и роли

### Основные сущности (Основная БД)
* `users` — пользователи с ролями.
* `animal_families` — семейства животных.
* `animal_species` — виды животных (связь M:1 с семействами).
* `zoos` — зоопарки.
* `zoo_species_bindings` — связь M:N зоопарков и видов.
* `tickets` — билеты с QR-кодами.
* `comments` — комментарии к зоопаркам.
* `promotions` — акции в зоопарках.

### Сущности в БД API
* `interesting_facts` — интересные факты (id, animal_species_name, text).

### Роли пользователей

| Роль | Код | Возможности |
| :--- | :--- | :--- |
| **Пользователь** | User = 1 | Просмотр, бронирование, комментарии |
| **Модератор** | Moderator = 10 | Управление животными, зоопарками, акциями |
| **Администратор** | Admin = 99 | Полный доступ |

## Реализация

### Real-time уведомления
Приложение использует SignalR для двух типов уведомлений:
1. `AnimalAppearedMessage` — при привязке новых животных к зоопарку.
2. `ZooPromotion` — периодическое уведомление об активных акциях (через Quartz, cron: `0 0 9-20 ? * *`).

### Особенности проекта
* Кастомная система авторизации на Cookie с claim-ами (Id, Role, UserName, Language).
* Атрибут `[AtLeastModerator]` для защиты действий модераторов.
* Атрибут `[Booking]` — проверка заполнения профиля перед бронированием.
* Валидация загружаемых изображений по magic bytes (JPEG/PNG).
* Динамическая фильтрация через Expression Trees (поиск по видам животных).
* Пагинация для зоопарков и видов животных.
* AJAX-комментарии с anti-forgery токенами.
* Адаптивный дизайн на CSS Grid и CSS Variables.

### Структура папок (AnimalWorld.Web)
* `Controllers/` — MVC контроллеры.
* `Views/` — Razor-представления.
* `Mappers/` — маппинг Model <-> ViewModel.
* `Models/` — ViewModel'и.
* `Helpers/` — вспомогательные классы (загрузка изображений).
* `Hubs/` — SignalR хабы.
* `Jobs/` — Quartz jobs.
* `Attributes/` — кастомные атрибуты авторизации.
* `wwwroot/` — статические файлы (CSS, JS, изображения).
